# VOXELCRAFT 2.1 — онлайн-мультиплеер

Сервер на Node.js (>=18), **без зависимостей** (свой WebSocket по RFC 6455). Один и тот же сервис отдаёт игру (`/`) и принимает WebSocket-подключения.

## Что проверено, а что нет
* Проверено автотестом `npm test` (локально, 2 клиента): создание комнаты, вход по коду, одинаковый seed, рассылка позиций и блоков, отказ на неверные/далёкие блоки, сундуки, переподключение по токену, мусорные и слишком большие сообщения.
* **Не проверено**: реальное соединение двух телефонов через интернет и работа внутри APK — для этого нужен развёрнутый сервер. Проверьте по шагам ниже.

## Запуск локально
```
cd voxelcraft-server
npm start            # http://localhost:8080
npm test             # протокольные тесты
```
Откройте `http://<IP-компьютера>:8080` с двух устройств в одной сети — для проверки. Для игры через интернет нужен хостинг с HTTPS/WSS.

## Деплой (WSS)
Любой хостинг для Node, который даёт HTTPS автоматически (Render, Railway, Fly.io, Koyeb):
1. Залейте папку `voxelcraft-server` в GitHub-репозиторий.
2. Render → New → Web Service → репозиторий. Build: пусто (или `npm install`), Start: `npm start`. Порт берётся из `PORT`.
3. Получите адрес вида `https://ваше-имя.onrender.com`. Игра открывается по нему же; WebSocket-адрес: `wss://ваше-имя.onrender.com`.
4. Проверка: `https://ваше-имя.onrender.com/health` → `ok rooms=0`.
Бесплатные планы «засыпают» — первое подключение может занять до минуты. Комнаты хранятся в памяти: при перезапуске сервера пропадают.

## Как играть вдвоём
1. Оба: Главное меню → **Мультиплеер**, введите **ник** и **адрес сервера** (`wss://...`; если игра открыта с самого сервера, адрес подставится сам).
2. Хозяин: **Создать комнату** → режим (Творческий/Выживание) → на экране появится **код из 5 символов** (также виден вверху в игре).
3. Друг: **Присоединиться к комнате** → ввести код. Список игроков: клавиша **Tab** (ПК) или кнопка 👥 (телефон).
4. Выход: Пауза → «Выйти из комнаты». Одиночный мир при этом не затрагивается и не перезаписывается.

## Сборка APK (Capacitor)
```
npm init -y && npm i @capacitor/core @capacitor/cli @capacitor/android
npx cap init VoxelCraft com.example.voxelcraft --web-dir=www
mkdir www && cp index.html www/index.html
npx cap add android && npx cap sync
```
В `android/app/src/main/AndroidManifest.xml` у `<activity>` добавьте `android:screenOrientation="sensorLandscape"` (горизонтальный экран). Разрешение `INTERNET` уже есть в шаблоне. Используйте только `wss://` (обычный `ws://` Android WebView блокирует). Затем `npx cap open android` → Build APK. В игре введите адрес сервера один раз — он запоминается.

## Что реально реализовано
* Комнаты с кодом, до 8 игроков, ники, список игроков, вход/выход в реальном времени.
* Позиция, поворот, поворот головы, ходьба и взмах рук других игроков (интерполяция), ник над головой.
* Синхронизация мира: установка/разрушение блоков (в т.ч. грядки, посевы, кровати, сундуки), сундуки (содержимое), время суток, сон.
* Сервер проверяет: формат и размер сообщений, диапазоны координат, допустимые id блоков, дальность (≤9 блоков от игрока), частоту (rate limit), нельзя ломать бедрок и непустой сундук, ограничен размер мира (300 000 правок).
* Переподключение: при обрыве клиент 12 раз пробует вернуться по токену (60 секунд слот игрока сохраняется), мир досылается заново.
## Что НЕ сделано / ограничения
* Сервер **не ведёт инвентари** игроков, поэтому не может проверить, есть ли у игрока блок, который он ставит, или не дюпнут ли предметы через сундук. Для публичных серверов нужна серверная модель инвентаря.
* Мобы и вода симулируются локально у каждого игрока (не синхронизируются). Здоровье/урон между игроками (PvP) не реализованы.
* Мир не сохраняется на диск на сервере (только в памяти комнаты).
* Чата нет.
